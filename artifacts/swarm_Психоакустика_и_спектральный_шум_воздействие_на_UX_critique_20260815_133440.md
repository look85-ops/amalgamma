# Психоакустика_и_спектральный_шум_воздействие_на_UX — замечания критика

1. Раздел 1.2 "Типы спектрального шума" декларативен и не интегрирован в фреймворк → Добавить аналитическую связку: для каждого типа шума в таблице указать, какой конкретный психоакустический механизм (из п. 2.1) объясняет его восприятие (например, "розовый шум воспринимается как мягкий из-за попадания основных гармоник в одну критическую полосу").
2. Принцип 3.1 "Динамическая адаптация" не подтверждён в примере из п.4 → Конкретизировать сценарий: в п. 4.3 "Адаптация" явно связать смену шума с изменением измеряемого контекста (например, "при снижении активности ввода с клавиатуры > 5 минут алгоритм интерпретирует это как усталость и инициирует переход на коричневый шум").
3. Техническая спецификация (п. 3.2) оторвана от практики → Вместо абстрактного описания API привести минимальную схему работы: "1. Осциллятор генерирует белый шум → 2. Биквадратный фильтр формирует целевой спектр (розовый/коричневый) → 3. GainNode регулирует амплитуду по данным датчиков".
4. Раздел 5 "Ограничения и риски" формален → Конкретизировать "потенциальный вред": добавить ссылки на существующие медицинские нормы (например, NIOSH) по безопасному уровню звукового давления для длительного прослушивания и требования к их соблюдению в гайдлайнах (п. 6.4).
5. Заключение дублирует введение, не давая нового вывода → Переработать, сфокусировавшись на практическом барьере: "Ключевое ограничение для внедрения — отсутствие готовых метрик для оценки эффективности аудио-UX, что требует предварительного создания оценочной системы на основе сочетания объективных (продуктивность) и субъективных (опрос SAM) методов".
