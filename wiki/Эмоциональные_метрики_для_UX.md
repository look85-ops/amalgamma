# Эмоциональные метрики для UX

*Последнее обновление: 2026-08-16 04:38:40*

---

Эмоциональные метрики являются инструментами для оценки эмоционального отклика пользователей на дизайн интерфейсов. Их адаптация для мультисенсорного дизайна особенно важна в случае использования спектрального шума, интерференционных паттернов и других философских категорий. Некоторые из ключевых инструментов: 1. SAM (Self-Assessment Manikin) — визуальная шкала для оценки эмоционального состояния. 2. PANAS (Positive and Negative Affect Schedule) — измеряет положительные и отрицательные эмоции. 3. AttrakDiff — оценивает восприятие эстетики и привлекательности интерфейса.
